# Профиль учебных отчетов

## Общая подача

Ориентироваться на учебный технический отчет: цель и условия,
нужная теория, расчет/исследование, объяснение результатов, заключение.
Тема раскрывается через работу с объектом. НИРС подробнее и сильнее опирается
на литературу; модельные ДЗ короче и насыщены схемами и графиками.

Сохранять причинные связи и естественные переходы «Для этого воспользуемся…»,
«Рассчитаем…», «По полученным данным…». Уместны безличная форма и умеренное «мы»
при описании рассуждения. Не писать от первого лица единственного числа без запроса.
Один абзац решает одну небольшую задачу: условия, выбор метода, наблюдение или
объяснение. После изображения и чисел нужен смысловой вывод.

Писать живым и понятным учебным языком, без заумных терминов. Сохранять инженерный
и научный стиль без излишней сухости. Соединять предложения причинными и смысловыми
связями; не превращать абзац в перечень коротких пассивных утверждений.
Давать явное подлежащее, когда оно естественно: «алгоритм», «фильтр», умеренное «мы».
Не придавать тексту тон статьи специалиста. Объяснять только нужные понятия.
Например: «После пороговой обработки монеты остались соединенными. Для их
разделения воспользуемся методом водораздела». Термины «маркер» и «затопление»
вводить с пояснением тогда, когда они понадобятся для описания метода.

Писать об опыте непосредственно: «При сравнении мы меняли нижний и верхний
пороги, а сглаживание и размер ядра оставили прежними». Убирать служебные
рассказы о папках, материалах преподавателя и подготовке отчета. Не объявлять
свойства пользовательского черновика обязательными условиями задания.
Не сопровождать обычный учебный результат оговорками об отсутствии эталона
или доказательств оптимальности, если такая оценка не входила в задачу.
Сохранять только ограничения, которые нужны для честного объяснения результата.

Ориентир глубины — возможность воспроизвести расчет и объяснить результат на защите.
Показывать параметры модели, основания выбора и один подробный расчет. Не заменять
содержание ни подробной инструкцией по интерфейсу, ни набором общих тезисов.
Не усложнять саму работу сверх задания и предоставленных материалов: качество
объяснения важнее количества методов, метрик и программных деталей.

## Структуры

Названия адаптировать к предмету: «Расчет элементов схемы» информативнее
универсального «Основная часть». Нумеровать содержательные разделы основной части;
введение, заключение и список источников оставлять без номера.

Общий порядок по умолчанию: содержание → текст работы → заключение → при
необходимости открытые источники и приложения. Титульный лист не создавать.
На странице содержания начинать видимую нумерацию с 2, далее продолжать по порядку.
Эти настройки профиля имеют приоритет над прежними образцами и общими
правилами ГОСТ. Текущие требования конкретного задания могут задавать иной состав.

### Лабораторная работа

1. Содержание без титульного листа, номер страницы 2 снизу по центру.
2. ВВЕДЕНИЕ: цель, задачи, объект, вариант/исходные данные, средства и существенные
   допущения. Для короткой ЛР можно начать непосредственно с цели по заданию.
3. Теоретическая часть: физический принцип, нужные формулы, обозначения,
   ограничения. Включать теорию, которая используется далее.
4. Практическая часть: установка/модель, условия, последовательность опытов,
   измерения, таблицы, графики, наблюдения. Подразделы соответствуют этапам задания.
5. Расчетная часть при необходимости: подстановка, результаты, сопоставление
   теории и эксперимента, отклонения. Можно встроить ее в практические этапы;
   не повторять расчеты ради шаблона.
6. Ответы на контрольные вопросы, если они есть; сохранить номера и смысл.
7. ЗАКЛЮЧЕНИЕ: результаты по задачам и ограничения.
8. СПИСОК ИСПОЛЬЗОВАННЫХ ИСТОЧНИКОВ, если нужен; только открытые источники.
   Приложения по необходимости.

### Расчетное или модельное ДЗ

Содержание → цель/краткое введение → исходные данные → расчет и обоснование выбора →
схема/модель → исследование → сравнение с условиями → заключение → источники.
Включать только подходящие этапы. Для ДЗ по фильтру достаточно синтеза,
определения характеристик и анализа разброса без большой теоретической главы.
Проверить каждое нормируемое значение, включая невыполненные требования.

### Обзорный отчет

Содержание → ВВЕДЕНИЕ с целью и границами → физические/
теоретические основы → устройство/методика → характеристики и применения →
сравнение подходов, ограничения и ошибки → ЗАКЛЮЧЕНИЕ → источники.
Объединять близкие разделы в коротком задании. Не создавать фиктивную
экспериментальную часть и не выдавать обзор за доказательство эффективности.

### НИРС

Для учебной НИРС: содержание → ВВЕДЕНИЕ (проблема, основание, цель,
задачи) → основы → сравнение и выбор подхода → методика/алгоритм → результаты,
оценка и ограничения → ЗАКЛЮЧЕНИЕ → источники → приложения по необходимости.

Для полного отчета о НИР по ГОСТ проверить состав по разделам 4–5 стандарта:
реферат и необходимые передние элементы; условия для списка исполнителей,
терминов, сокращений и приложений. Не удалять обязательный элемент из-за его
отсутствия в пользовательском фрагменте. Не придумывать регистрационные номера,
согласования, внедрение или экономическую эффективность.

## Полнота

Для каждого этапа проверить: зачем он нужен; какие условия заданы; какой метод
и основание используются; где результат и единицы; что он означает; выполнено ли
требование. Все пункты задания должны иметь содержательный ответ.

Не задавать постоянное число страниц, рисунков и источников. Объем образцов
сильно зависит от изображений. Короткий конкретный вывод может быть полноценным.
Если список литературы не нужен по заданию и внешние источники не использованы,
опустить его. Материалы преподавателя служат основой выполнения задания,
но не включаются в библиографию; название файла с данными допустимо в тексте.
Не описывать в отчете, откуда были взяты эти материалы, и не ставить на них
ссылки в основном тексте. Открытый список источников оформлять TNR 14 пт.

## Пример конструкции

Условный пример, не данные пользователя:

«По расчету коэффициент усиления равен 10. В модели получено значение 9,8;
относительное отклонение от расчетного составляет 2 %. Оно может быть связано
с ограниченным коэффициентом усиления операционного усилителя. Для проверки этой
причины требуется сравнение с моделью идеального усилителя».

Сохранять разграничение расчета, наблюдения и предположения. Не заимствовать
числа примера для новой работы.
