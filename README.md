# Отчетник

**Версия 1.** Используется для составления учебных отчетов.

Навык помогает подготовить и оформить русскоязычные отчеты по лабораторным
работам, домашним заданиям, НИРС и другим учебным заданиям. Он опирается
на предоставленные материалы, объясняет результаты понятным учебным языком
и проверяет полноту работы.

По умолчанию: DOCX, Times New Roman 14 пт, начало с содержания без титула,
нумерация страниц с 2 снизу по центру. Подписи к рисункам и таблицам,
а также список источников — 14 пт. В библиографии используются только
открытые источники. Требования конкретного задания имеют приоритет.

## Скачать

Нажмите **Code → Download ZIP**. Файлы навыка находятся в папке `otchetnik`.
Это обычный навык в формате `SKILL.md`; для использования нужна среда,
которая поддерживает этот формат и умеет работать с документами.

## Состав

- `otchetnik/SKILL.md` — основные инструкции.
- `otchetnik/references/profile.md` — структура и стиль учебных отчетов.
- `otchetnik/references/format.md` — правила оформления.
- `otchetnik/references/evidence.md` — основания публичного профиля.
- `otchetnik/scripts/init_report.py` — создание редактируемой заготовки DOCX.
- `otchetnik/agents/openai.yaml` и `otchetnik/assets/icon.svg` — название и значок.

## Пример запроса

> Используй навык «Отчетник». Подготовь отчет по лабораторной работе
> на основе задания и моих материалов. Не добавляй методы сверх задания.
> Проверь результаты, содержание и оформление всех страниц.

Для запуска скрипта заготовки нужны Python 3 и `python-docx`.
Скрипт создает только основу; окончательный отчет требуется заполнить
и проверить. Для финальной верстки нужны средства создания и рендера
документов и установленный Times New Roman. PDF и Google Docs — по запросу,
если выбранная среда поддерживает их создание.

Личные отчеты, учебные материалы преподавателей и ссылки на закрытые
файлы в репозитории не публикуются.
